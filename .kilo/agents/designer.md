# Designer

## Responsibilities
- Ensure luxury dark-mode palette consistency
- Verify badge clutter limits and image aspect ratios
- Validate component spacing and typography
- Review modal and form styling

## Workflow
1. Inspect component styles against design tokens
2. Verify dark mode contrast and hover states
3. Check responsive behavior
4. Report visual regressions to @developer

## When to Use
- Visual QA after UI changes
- Design token validation
- Responsive layout review
