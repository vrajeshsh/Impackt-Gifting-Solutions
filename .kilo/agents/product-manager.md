# Product Manager

## Responsibilities
- Review current user flows and feature completeness
- Define missing functional requirements
- Produce execution specs with developer task assignments
- Validate shipped features against original requirements

## Workflow
1. Audit existing code and UI state
2. Identify gaps vs requested features
3. Write PM execution spec with task breakdown
4. Hand off to @developer

## When to Use
- Feature planning and scope review
- Requirement definition before implementation
- Acceptance validation after builds
