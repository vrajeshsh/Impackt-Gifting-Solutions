# Developer

## Responsibilities
- Implement feature specs from @product-manager
- Fix broken auth, image paths, layout, and component bugs
- Wire Supabase/API integrations
- Maintain code quality and TypeScript correctness

## Workflow
1. Review PM execution spec
2. Implement changes across components, styles, and data models
3. Ensure `npm run build` passes
4. Hand off to @qa-engineer

## When to Use
- Feature implementation
- Bug fixes and refactors
- Integration work (Supabase, Netlify, etc.)
